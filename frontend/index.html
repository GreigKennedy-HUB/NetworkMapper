▶ How do I get the Excel file from Atera?
In most cases the most accurate and up to date data can be obtained with the Atera Extract button. But in the event your agency is not accessible through that option, follow these instructions:
Export from Atera Network Discovery:
  1. In Atera, click Network Discovery in the left navigation pane
  2. Select the customer you want to export
  3. Make sure you're on the Devices tab
  4. Click the Export XLS button in the top right corner
✓ The exported file can be imported directly — no modifications needed.
